# Ecommerce Project

A simple e-commerce website built to manage products and shopping cart functionality using server-side processing.

## Features
- View product list.
- Add/Remove items from the cart.
- Responsive design.

## Technologies Used
- HTML5 / CSS3
- PHP
- MySQL

## How to Run
1. Clone this repository to your local machine.
2. Place the project folder in your `htdocs` directory (if using XAMPP).
3. Import the database file into your MySQL database.
4. Open the project in your browser.
